# 管理员凭据修复部署说明

本次修复需要同时发布 TangSengDaoDaoServer 与 TangSengDaoDaoServerLib。

- 启动时执行 `modules/user/sql/user-20261112-01.sql`，为 `user` 表增加 `auth_version`。必须先完成迁移，再接收业务请求；现有模块安装流程会在注册路由前执行迁移。
- 升级后，缺少会话版本的旧管理员 Token 被拒绝，管理员需要重新登录。普通用户登录协议不变。
- 管理员每次请求实时核验数据库中的账号、角色、启用/注销状态和会话版本；数据库查询失败时拒绝认证。该核验会给每个携带管理角色的请求增加一次数据库查询。
- 所有应用内密码写入路径原子更新密码与随机会话版本，撤销该账号此前所有管理 Token；重新使用历史密码也不会恢复旧 Token。管理账号登录不复用历史 Token 字符串。
- 公共短信找回密码、找回密码短信发送和 Web3 重置密码不再支持管理账号。管理员应使用已认证的管理流程处理密码变更；丢失超级管理员凭据时需由运维执行受控恢复。
- 修改昵称只更新当前 Token 的名称，保留凭据元数据和剩余 TTL，不续期、不恢复已撤销或过期的 Token。对历史无 TTL 的普通会话补充配置中的最长有效期。

验证使用独立内存 SQLite 和临时 Unix socket Redis，不连接生产数据库或 Redis。未进行线上部署或线上数据变更。
